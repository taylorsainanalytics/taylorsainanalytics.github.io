# Taylor Sain Portfolio - Consolidated GitHub Pages Release

This is a complete, consolidated website package (not a collection of incremental patches).

## Contents
- index.html: compact homepage, 180px portrait beside the headline
- projects.html and projects-library.css: expandable Project Library
- resume.html: Experience page
- projects/: existing detailed case studies plus ESPN Academy
- assets/images/espn-enrollment-dashboard-sanitized.png: portfolio dashboard visual with School A-E
- style.css, script.js, images, PDF and supporting assets

## Safe deployment
1. Download a ZIP backup of your current GitHub repository, or create a backup branch.
2. In the GitHub repository, upload the **contents** of this package to the repository root, keeping the folder structure.
3. Replace matching website files. Remove superseded website files only after checking they are not referenced.
4. **Keep** `.git`, `.github`, `CNAME`, `.nojekyll`, LICENSE, and any GitHub Pages configuration or custom-domain files already in the repository. Do not delete the repository.
5. Commit once, wait for GitHub Pages deployment, then hard-refresh.
6. Verify homepage, Experience, Project Library, ESPN Academy and Proactive Compliance case studies.
