# Taylor Sain Portfolio

Personal analytics portfolio built with HTML, CSS, and JavaScript and published with GitHub Pages.

## Before publishing

1. Add a PDF resume at `assets/Taylor-Sain-Resume.pdf`.
2. Replace or confirm the LinkedIn and email links in `index.html`.
3. Add sanitized project screenshots to `assets/images/`.
4. Expand the case study pages in the `projects/` folder.

## GitHub Pages settings

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`
